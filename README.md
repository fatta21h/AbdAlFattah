# تطبيق عبد الفتاح — مشروع Android مبدئي

هذا مشروع مصدر أولي لتطبيق أرشفة إيصالات التحويلات، يعمل محلياً دون إنترنت بعد تثبيته.

## الميزات الموجودة في النسخة الأولية
- إضافة إيصال: اسم العميل، الهاتف، المبلغ بالجنيه السوداني، رقم العملية، ملاحظات.
- اختيار صورة إيصال من الهاتف.
- البحث بالاسم أو الهاتف أو رقم العملية.
- إجمالي المبالغ المسجلة اليوم.
- حذف إيصال بعد التأكيد.
- تخزين البيانات في قاعدة SQLite محلية على الجهاز.

## البناء
1. نزّل وثبّت Android Studio على كمبيوتر.
2. افتح مجلد المشروع `AbdAlFattahApp`.
3. انتظر Gradle Sync ثم اختر Build > Build APK(s).
4. اختبر التطبيق قبل إدخال بيانات حقيقية.

## ملاحظات مهمة
- هذا ملف مشروع مصدر، وليس APK جاهزاً للتثبيت.
- النسخ الاحتياطي السحابي غير مضاف في هذه النسخة.
- بيانات التطبيق محلية؛ احذف التطبيق أو امسح بياناته قد يؤدي إلى فقدها. أضف تصديراً/نسخاً احتياطياً قبل الاستخدام التجاري.
- لم يُختبر البناء في بيئة Android SDK هنا؛ قد يتطلب ضبط إصدار Gradle/Android Studio حسب البيئة.
